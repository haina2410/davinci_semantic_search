# Notion issue tracker

- [Davinci Plugin](https://app.notion.com/p/4157c7b967a180138526ed746115b5a8)
- [Active PRD](https://app.notion.com/p/41e7c7b967a181de8346f3a46c128802)
- [Implementation tickets](https://app.notion.com/p/41e7c7b967a181c597aacf0d5b0d2852)

Use the Notion connector. Each ticket includes acceptance criteria and a list of prerequisite ticket links. A ticket is available once its prerequisites are complete. Mark a ticket complete only after verifying its acceptance criteria. Use **Cần kiểm chứng** for implemented work that still needs a live Resolve or hardware check.

The `Triage` property uses the default skill labels `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. `Progress` tracks implementation separately.
